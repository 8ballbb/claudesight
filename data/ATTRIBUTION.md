# Bundled data attribution

## claude-code-settings.schema.json

The Claude Code settings JSON Schema, from SchemaStore.

- Source: https://www.schemastore.org/claude-code-settings.json
- Upstream: https://github.com/SchemaStore/schemastore (`src/schemas/json/claude-code-settings.json`)
- Licence: Apache-2.0

Refreshed by `scripts/refresh-settings-schema.mjs`; provenance (the Claude Code
version it was synced to, and when it was fetched) is recorded in
`settings-schema.meta.json`. It is bundled rather than fetched at runtime
because the app makes no outbound network requests.
